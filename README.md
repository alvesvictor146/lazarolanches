# Lázaro's Burger - Cardápio Online & Lanches Artesanais 🍔🔥

Cardápio digital moderno e interativo da hamburgueria **Lázaro's Burger (Est. 2023)**.

## ✨ Recursos

- 🛵 **Pedido Direto no WhatsApp**: Pedido formatado com seleção de itens, quantidade, observações e forma de pagamento.
- 📍 **Localização Automática por GPS**: O cliente pode capturar sua localização precisa usando o sensor GPS do celular ou digitar o endereço manualmente.
- 🛍️ **Sacola de Compras**: Adicione múltiplos itens e finalize o pedido completo em um único clique.
- 🎨 **Design & Efeitos Premium**:
  - Reveal Animations e Stagger Transitions
  - Text Reveal + Character Reveal
  - Parallax (Scroll & Mouse)
  - Magnetic Buttons
  - Mouse Follow Glow
  - 3D Hover Tilt nos Cards de Lanches
  - Microinterações sonoras com Web Audio API

## 🚀 Como Executar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador ou rodar um servidor HTTP local:

```bash
# Com Python:
python -m http.server 8080

# Ou com npx serve:
npx serve .
```
